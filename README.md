# Diagrams Editor

Mermaid記法のインポート/エクスポートに対応した、フローチャート用のWebダイアグラムエディタです。
React + Vite + React Flow (@xyflow/react) + dagre で構築しています。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで表示されたURL(デフォルト http://localhost:5173)を開きます。

## 主な機能

- **スクラッチ編集** — 左のライブラリから図形をクリック / ドラッグ&ドロップで配置。キャンバスのダブルクリックでも追加できます
- **接続** — ノードにホバーすると表示されるハンドルをドラッグして接続線を作成
- **編集** — ノードをダブルクリックでタイトルをインライン編集。選択すると右のプロパティパネルでタイトル・説明・形状・カラー・アイコン、接続線のラベル・線種(実線/点線/太線)・矢印を変更可能
- **接続タブ** — 選択ノードの入出力接続を一覧表示し、クリックで接続線を選択
- **Mermaidインポート** — `flowchart TD` / `graph LR` などのフローチャート記法を貼り付けてインポート(dagreで自動レイアウト)
- **Mermaidエクスポート** — 現在の図をMermaidテキストとして出力・コピー
- **自動レイアウト** — 縦(TB) / 横(LR) の切り替えと整列
- **Undo / Redo** — ⌘Z / ⇧⌘Z(ツールバーのボタンでも可)
- **エクスポート** — PNG画像 / JSONファイル(位置情報を保持した保存・読み込み)
- **テンプレート** — オンボーディングフロー・承認フローなどのサンプルを収録
- **自動保存** — 編集内容はlocalStorageに自動保存され、リロード後も復元されます

## 対応しているMermaid記法(フローチャートのサブセット)

- ヘッダー: `flowchart` / `graph` + 方向 `TB` `TD` `BT` `LR` `RL`(BT→TB、RL→LRに正規化)
- ノード形状: `[長方形]` `(角丸)` `([スタジアム])` `((円))` `{ひし形}` `{{六角形}}` `[/平行四辺形/]` `[(円柱)]` `[[サブルーチン]]`
- エッジ: `-->` `---` `-.->` `-.-` `==>` `===` `<-->`、ラベルは `-->|ラベル|` と `-- ラベル -->` の両形式
- 複数接続の連鎖 `A --> B --> C`、`&` によるグループ `A & B --> C`
- ラベル内の `<br/>` は改行として取り込み(1行目がタイトル、2行目以降が説明になります)
- `subgraph` / `classDef` / `style` などのスタイル定義行は読み飛ばします(エラーにはなりません)

## プロジェクト構成

```
src/
  App.tsx                 エディタ本体(状態管理・Undo/Redo・入出力)
  palette.ts              ノードライブラリの定義(形状・色・アイコン)
  templates.ts            テンプレート(Mermaid文字列)
  mermaid/parseMermaid.ts Mermaidフローチャートのパーサー
  mermaid/toMermaid.ts    Mermaidテキストへのシリアライザ
  flow/layout.ts          dagreによる自動レイアウト
  flow/convert.ts         Mermaid → React Flow変換
  flow/edgeUtils.ts       エッジのスタイル・ハンドル決定
  components/             UIコンポーネント(ノード・ツールバー・パネル等)
```
